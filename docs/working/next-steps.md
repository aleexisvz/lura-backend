# Next Steps — Lura Platform

## Short Term
- **Database Persistence for Book Progress**: Migrate file-based `book-progress.json` store into a dedicated PostgreSQL Prisma model.
- **Bookmarks & Annotations Sync**: Add dedicated endpoints to sync book annotations, highlights, and bookmarks across devices.

## Medium Term
- **User Collections & Custom Shelves**: Expand the `/collections` module to allow users to create custom playlists/shelves for manga and books.
- **Offline Reading & PWA Support**: Implement service worker cache strategies for reading on mobile/tablet devices without a constant network connection.

## Long Term
- **Enhanced Reader Customization**: Continuous scroll / webtoon mode for vertical manga reading.
- **Reading Achievements & Badges**: Unlockable achievements tied to reading milestones and XP level tiers.
