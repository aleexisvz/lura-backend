# Lura - Project Plan

## Vision

Lura is a unified digital library platform where users can:

- Read manga (image-based)
- Read books (EPUB)
- Track progress
- Track reading time
- Build a personal reading profile

---

## Key Concept

Single library, multiple formats:

- Manga
- Books

---

## Content Model

Content is global, not user-owned.

- Admin uploads content
- All users can access it

---

## User Features (Current + Planned)

- Reading manga
- Tracking progress (MangaProgress)
- Reading sessions (time tracking)
- Continue reading
- Stats (future)
- Collections (future)
- Gamification (future)

---

## Long-Term Vision

- Full reading ecosystem
- Multi-format support
- Profile system with stats and levels
- Mobile support (later phase)
